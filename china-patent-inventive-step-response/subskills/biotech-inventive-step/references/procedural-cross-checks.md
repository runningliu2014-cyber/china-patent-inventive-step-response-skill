# 生物技术相关程序与其他法条核查

仅在审查意见同时提出相应问题时使用。本清单不把创造性分析扩展为无关的全面合规审查。

| 问题 | 核查材料 | 与创造性分析的边界 |
|---|---|---|
| 保护客体 | 权利要求主题、专利法第五条和第二十五条相关意见 | 单独回应，不以客体合规证明创造性 |
| 充分公开 | 实施例、制备方法、功能验证、可重复性 | 评价效果证据是否可依赖，但不混同法条 |
| 生物材料保藏 | 保藏单位、日期、编号、证明和样品对应关系 | 确认权利要求和实验对象，不以保藏本身证明创造性 |
| 序列表 | SEQ ID、序列版本及与权利要求的一致性 | 为序列差异比对提供准确对象 |
| 遗传资源来源 | 登记表、直接和原始来源 | 单独核查；登记表内容不得当然作为修改说明书或权利要求的基础 |
| 清楚与支持 | 功能性限定、同源性阈值、变体范围 | 防止修改后权利要求超出实际技术贡献 |

输出时把“创造性”“充分公开”“清楚支持”“程序补正”分成不同问题和结论，避免以解决一个问题代替其他问题。
