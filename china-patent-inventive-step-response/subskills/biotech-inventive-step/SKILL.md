# 生物技术创造性专题

本 Skill 在通用创造性工作流上增加生物技术领域的保护主题识别、结构差异、亲缘关系和效果可预期性分析。在通用的权利要求解释、D1 选择、区别特征和技术启示判断中同步应用相关专题规则，再形成综合结论。

## 1. 识别保护主题和限定方式

逐项确定权利要求保护的是：

- 基因或 DNA 片段；
- 多肽或蛋白质；
- 重组载体；
- 转化体；
- 融合细胞；
- 单克隆抗体；
- 微生物本身；
- 微生物应用；
- 同时包含多种主题的组合、制备方法或用途。

同时记录权利要求如何限定该主题：序列、结构、功能、来源、宿主、杂交瘤、保藏号、分类学特征、用途或制备步骤。审查员使用的主题规则与实际权利要求不一致时，在分析记录中定位差异，并核实适用规则；正式表达交由法律写作模块处理。

## 2. 选择专题参考

只读取与当前权利要求有关的文件：

- 基因、多肽/蛋白质、重组载体、转化体、融合细胞、单克隆抗体：读取 [references/genetic-engineering.md](references/genetic-engineering.md)。
- 微生物本身或微生物应用：读取 [references/microorganisms.md](references/microorganisms.md)。
- 审查意见还涉及保护客体、充分公开、保藏、序列表或遗传资源来源时：再读取 [references/procedural-cross-checks.md](references/procedural-cross-checks.md)。

不要仅因案件属于生物技术就加载全部参考文件。

## 4. 非显而易见性重点

### 结构差异与性能变化

序列相似度、同源性或分类学接近程度只是证据的一部分。需要说明：

- 差异位于何处，是否涉及决定功能或用途的关键区域；
- 差异导致何种性能改变；
- 申请日前现有技术是否能预见该改变；
- 该效果是否由当前权利要求限定的结构或组合产生。

不得使用“序列不同所以有创造性”或“相似度高所以无创造性”的单因素结论。

### 亲缘关系

亲缘关系远近应与保护主题、已知功能、筛选范围和效果可预期性一起评价，不采用“不同物种必然有创造性”的简单阶梯。

### 实验与成功预期

区分：

- 现有技术给出明确目标、有限候选和可预期结果；
- 仅提出研究可能性或宽泛方向；
- 需要多层筛选、随机突变、复杂工程或结果高度不确定。

“能够尝试”不等于“合理预期成功”。同时，实验工作量大本身也不证明创造性。

## 5. 与通用流程衔接

1. [office-action-analysis](../office-action-analysis/SKILL.md)：确认审查员引用的是哪一类专题规则；
2. [distinguishing-features](../distinguishing-features/SKILL.md)：把关键序列、结构、组合和性能关系落实到当前权利要求；
3. [obviousness-assessment](../obviousness-assessment/SKILL.md)：判断现有技术是否给出具体改造路径和合理成功预期；
4. [secondary-considerations](../secondary-considerations/SKILL.md)：在有证据时评价预料不到效果；
5. [claim-amendment-strategies](../claim-amendment-strategies/SKILL.md)：把真正贡献性能的限定合法写入权利要求；
6. [legal-writing-style](../legal-writing-style/SKILL.md)：形成正式答辩。

## 6. 输出

- 保护主题与适用规则；
- 关键结构、序列、来源或分类差异；
- 性能变化及原始依据；
- 现有技术启示和成功预期；
- 审查员规则适用或事实认定中的缺口；
- 需要补充的序列比对、实验、文献或保藏材料；
- 对通用三步法结论的专题修正。
