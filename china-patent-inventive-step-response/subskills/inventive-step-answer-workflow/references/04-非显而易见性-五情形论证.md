# 审查认定情形路由

本参考是索引，不重复保存非显而易见性规则。

| 审查认定 | 首要任务 | 使用 Skill |
|---|---|---|
| D2/Dn 公开区别特征 | 核实公开、作用、动机、相容性和成功预期 | [obviousness-assessment](../../obviousness-assessment/SKILL.md) |
| 区别特征属于公知常识 | 明确具体领域、具体问题、惯用性和依据 | [obviousness-assessment](../../obviousness-assessment/SKILL.md) |
| 属于常规手段或常规变型 | 追问起点、选择动机、改造条件和可预期结果 | [obviousness-assessment](../../obviousness-assessment/SKILL.md) |
| 审查员遗漏、合并或错位差异 | 重新建立权利要求—D1 对比 | [distinguishing-features](../../distinguishing-features/SKILL.md) |
| 技术效果可以预期 | 比较申请日前预期与实际效果及证据 | [obviousness-assessment](../../obviousness-assessment/SKILL.md)、[secondary-considerations](../../secondary-considerations/SKILL.md) |
| 审查员推理链存在缺口 | 将已确认缺口转化为论点 | [challenge-examiner-reasoning](../../challenge-examiner-reasoning/SKILL.md) |
| 现有权利要求难以克服 | 设计有原始依据的限缩 | [claim-amendment-strategies](../../claim-amendment-strategies/SKILL.md) |

同一特征可能对应多种认定。先建立一条完整证据链，再选择模块；不要按照对比文件数量或标签机械组织答复。
