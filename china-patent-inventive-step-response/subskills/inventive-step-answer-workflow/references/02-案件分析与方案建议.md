# 案件方案比较

本参考用于阶段 C。先完成事实和三步法分析，再比较方案；不要先决定“必须修改”后倒推理由。

## 1. 案件结论摘要

用简短文字说明：

- 当前最强的创造性论点；
- 审查员容易补正的薄弱论点；
- 现有权利要求的主要风险；
- 可用于修改的贡献特征；
- 仍需核实的事实或证据。

## 2. 方案形成条件

只有存在实质不同路径时提供多个方案。常见方向包括：

- 不修改或最小修改，通过事实与技术分析支持现有方案；
- 补入一组贡献特征，平衡范围与授权前景；
- 进一步限缩，优先降低授权风险。

方案数量服从案件事实，不固定为两个、三个或四个。

## 3. 方案卡

按方案实际内容记录；不修改方案注明沿用的权利要求版本，不填写不存在的修改依据：

| 项目 | 内容 |
|---|---|
| 采用的独立权利要求 | 不修改时标明版本；修改时提供完整拟议文字或明确修改指令 |
| 逐处原始依据 | 权利要求、说明书段落或附图位置 |
| 新的区别特征 | 相对于 D1 重新确定 |
| 技术效果与问题 | 修改后重新确定 |
| 技术启示结论 | 相对于全部引用依据重新分析 |
| 授权收益 | 该方案解决哪些审查缺陷 |
| 范围损失 | 被排除的实施方式及可能规避空间 |
| 法律与程序风险 | 第33条、清楚支持、针对性等 |
| 待确认事项 | 需要用户或发明人决定的内容 |

## 4. 比较与推荐

| 方案 | 证据强度 | 授权前景 | 保护范围 | 程序风险 | 推荐理由 |
|---|---|---|---|---|---|

授权前景只作相对评估，避免没有依据的百分比、星级或“必然授权”。

推荐时说明最关键的权衡。若存在一个明显优选方案且不需要新增授权，可以明确假设后继续；若选择会实质改变保护范围或商业目标，交由用户决定。

## 5. 后续答复

对非第一次答复，方案还应说明：

- 哪些前次事实和证据继续有效；
- 哪些论点被审查员具体回应；
- 本次新增了什么事实、证据、推理或修改；
- 本次论述相对于前次答复的实质推进。
