# 其他因素证据清单

本参考只用于收集材料。是否成立及如何影响结论由 [secondary-considerations](../../secondary-considerations/SKILL.md) 判断。

| 因素 | 可收集材料 | 关键关联 |
|---|---|---|
| 预料不到的技术效果 | 原始实验、适当对照、测试方法、申请日前技术预期 | 效果由哪项权利要求特征导致 |
| 技术偏见 | 申请日前教科书、标准、综述、代表性文献 | 该认识为何会阻止采用本申请路径 |
| 长期未解决的难题 | 需求历史、既有失败方案、行业记录 | 本申请如何实际解决同一问题 |
| 商业成功 | 销售、许可、市场采用、客户材料 | 成功是否来自技术贡献而非价格、品牌或营销 |
| 行业评价 | 奖项、专家评价、第三方验证 | 是否具体评价要求保护的技术贡献 |

## 记录要求

每份材料注明：

- 名称、作者或出具方；
- 形成或公开日期；
- 可核验位置；
- 证明对象；
- 与权利要求特征的联系；
- 可能的不利内容或替代解释。

没有足够关联的奖项、产业化规模、发明人资历和研发投入仅作背景，不作为独立创造性论点。
