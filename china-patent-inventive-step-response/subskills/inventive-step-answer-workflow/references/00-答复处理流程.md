# 材料与程序核查清单

本参考只用于完整案件的阶段 A，不保存三步法实体规则。

| 材料 | 状态 | 版本/日期 | 用途 | 缺失影响 |
|---|---|---|---|---|
| 审查意见正文及附件 | | | 复原审查理由 | |
| 当前有效权利要求 | | | 确定评价对象 | |

对关键材料注明“已取得全文 / 只有节选 / 无法取得”。

## 程序

核查：

- 申请日及主张的优先权日；
- 对比文件公开日和被援引内容的公开基础；
- 通知书类型、发文日和答复期限；
- 当前审查依据的权利要求版本；
- 是否存在前次答复、补充检索、新证据或新理由；
- 用户要求的是分析、方案、成稿还是文件交付。

优先权或现有技术资格无法确认时，不作确定性结论。

## 论证链完整性

逐权利要求确认审查意见是否写明：

```text
D1
→ D1 公开内容
→ 区别特征
→ 技术效果
→ 实际技术问题
→ 启示来源与结合理由
→ 整体显而易见性结论
```

缺失环节记录为“审查意见未说明”，不要自行补齐。

## 前次答复复盘

后续审查意见额外记录：

| 前次主张 | 前次证据 | 审查员本次回应 | 是否真正解决 | 本次处理 |
|---|---|---|---|---|

不得仅因前次论点未被接受就完全放弃；先判断是证据不足、事实错误、表达不清，还是审查员已经给出新的实质理由。

## 行动边界

可以建议补材料、与发明人核实或与审查员沟通。未经用户另行授权，不发送信息、不拨打电话、不提交文件。
