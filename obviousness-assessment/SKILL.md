# 技术启示与显而易见性判断

第三步判断申请日前的现有技术整体是否会使本领域技术人员在面对实际技术问题时，有动机改进 D1，并能够获得权利要求限定的完整技术方案。

区别特征在另一来源中作用相同，是可能存在技术启示的重要信号，须结合下述证据链综合评价。

## 输入

使用 `distinguishing-features` 的输出：

- D1；
- 区别特征及合理分组；
- 每组差异达到的技术效果；
- 实际解决的技术问题；
- 审查员主张的启示来源。

输入不完整时先补齐，不直接跳到“有/无创造性”。

## 技术启示证据链

对每个关键区别特征或相互作用的特征组，依次核查以下问题。

### 1. 来源是否真实公开相关手段

确认 D2/Dn、同一文件其他部分或公知常识实际给出的技术信息、上下文及准确位置。上位概念、功能相似和事后抽取的局部语句不当然等于公开了所需手段。

### 2. 该手段在来源中的作用是什么

比较其技术语境、解决的问题、发挥的功能和实现的效果。作用相同通常增强启示判断；作用不同通常削弱启示，但仍须结合现有技术整体判断，避免把“问题名称不同”当作唯一否定理由。

### 3. 为什么会用于改进 D1

寻找申请日前可识别的动机，例如 D1 明示的缺陷、领域共同需求、D2 的明确建议或公知的解决路径。不得以本申请方案本身作为选择 D2、重新表述问题或排列组合的理由。

### 4. D1 与该手段是否相容

核查：

- 基本原理、用途和工作条件是否兼容；
- 引入手段是否会破坏 D1 的目的或必要结构；
- 来源是否存在相反教导；
- 是否需要额外、未被说明的改造才能结合。

D1 缺乏改进基础时，即使 D2 出现相同手段，也不能跳过相容性分析。

### 5. 能否获得完整方案并合理预期成功

判断组合后是否实际得到权利要求中的结构、步骤、参数、顺序和相互作用。逐个特征均有来源时，继续核查这些特征之间的关系。对于可预测性较低的领域，区分“值得尝试”“能够尝试”和“有合理成功预期”。

上述因素共同用于评价证据链，按案件争点确定权重。缺少关键环节时，应说明它如何削弱审查员结论。

## 把核查结果写成实质论证

先按照审查意见原意，重建其最有依据的组合路径：以 D1 的具体方案为起点，引入来源中的何种手段，保留或改变哪些结构、步骤及条件，预期得到什么结果。区分审查员已提出的理由和为检验论点而考虑的可能反论，后者不得归于审查员。

围绕影响结论的关键改造展开分析：

- 交代 D1 的工作方式，以及来源中相关手段发挥作用所依赖的条件，并定位原文。
- 具体说明将该手段用于 D1 后的技术后果。主张不相容、破坏原理或仍需额外改造时，写清受影响的部件、步骤或关系及因果依据。
- 核查该后果能否通过本领域常规调整消除。需要改造、多次选择、跨领域或存在其他可选路径，本身均不足以证明非显而易见性；说明现有技术对该具体选择的指引及其可预测性。
- 指明组合结果与当前权利要求整体之间仍有何关键差距，以及该差距为什么影响所确定技术问题的解决。若现有技术已给出充分指引，如实评价，不为了答辩制造障碍。

每个主要论点至少应让读者看清：引用了什么事实、这些事实产生什么技术后果、该后果怎样影响组合判断。按案件需要组织自然段，不要求固定标题或机械填满所有项目。

结论与理由保持对应：单篇文件未公开某特征时，还须分析其他来源；文件没有明示组合建议时，还须分析隐含动机和公知常识；主张技术障碍时须有具体依据。保留“审查意见尚未充分说明”和“现有证据支持缺乏技术启示”之间的强度差别。

提交前检验最强反论：若同作用手段、常规替换或有限选择足以解释组合路径，说明其对本方论点的影响。只有结果确实超出申请日前合理预期且证据充分时，才主张预料不到效果。

## 三类启示来源

### 另一份或多份对比文件

逐文件分析，不把 D2 的一个实施方式与 D3 的另一个实施方式无理由拼接。组合层级越多，越需要说明选择顺序、动机和相容性。

### 同一文件其他部分

确认被引用部分与 D1 所采用的实施方式是否属于可结合的技术语境，不能因为在同一文献中出现就当然组合。

### 公知常识

记录审查员认定的：

- 相关技术领域；
- 具体技术问题；
- 所谓惯用手段；
- 认定理由和证据。

申请人提出有根据的异议时，评价是否需要教科书、技术词典、技术手册、标准或综述等材料。个别专利文献的存在不当然证明普遍公知。

## 整体评价

逐项核查后回到权利要求整体：

1. 关键特征是否功能上相互支持或协同；
2. 现有技术是否给出了相同的组合关系；
3. 审查员是否改变了特征在原文中的作用或条件；
4. 从 D1 到完整方案的路径是否需要多次选择；
5. 所谓成功预期是否覆盖本申请实际达到的效果。

不要以区别特征数量多、权利要求范围窄或每个孤立特征分别已知直接代替整体判断。

## 输出

| 特征/特征组 | 启示来源及出处 | 来源中的作用 | 改进 D1 的动机 | 相容性/反向教导 | 成功预期 | 结论强度 |
|---|---|---|---|---|---|---|

随后给出：

- 审查员论证中成立的环节；
- 缺失或证据不足的环节；
- 最有依据的答复论点、可能的反论及其影响；
- 针对权利要求整体的显而易见性结论；
- 需要补充的技术说明、实验或证据。

分别写明结论方向和证据强度：方向为“显而易见 / 非显而易见 / 尚不能判断”，强度为“证据充分 / 有一定依据 / 材料不足”，并解释其原因。有一定依据但未能确定时，可表述为倾向性判断；不强制弱化证据充分的结论。“证据充分”须指向具体结论，不能单独作为显而易见性判断。
