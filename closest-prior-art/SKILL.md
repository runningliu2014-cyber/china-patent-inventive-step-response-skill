# 最接近现有技术评价

本 Skill 只解决“从哪项现有技术出发”以及“审查员对该文件公开内容的理解是否准确”。不得预设审查员选择的 D1 通常正确，也不得仅因存在另一个更接近的文件就直接得出权利要求具有创造性。

## 基本原则

选择最接近现有技术应综合考虑技术领域、用途、所解决的技术问题、技术效果、技术方案和共同特征。优先考虑与发明所要解决的技术问题相关联、适合作为现实改进起点的现有技术；共同特征数量与其他因素一并权衡。

D1 是否合理与 D1 是否公开某个具体特征是两个问题，分别作答。

## 操作步骤

### 1. 确定候选起点

至少记录：

| 候选文件 | 技术领域/用途 | 面对的问题 | 核心构思 | 与权利要求共同内容 | 作为起点的理由 |
|---|---|---|---|---|---|

只在材料中存在其他现实候选时比较多个起点；不要为了形式完整虚构候选文件。

### 2. 整体理解候选文件

基于全文和附图说明其完整技术方案，不从不同实施方式中任意抽取互不关联的特征。对隐含公开或附图推断单独标识其推理依据。

### 3. 评价起点质量

依次回答：

1. 文件是否与本发明技术问题或用途具有实际关联；
2. 其技术方案是否具有朝本发明方向改进的现实基础；
3. 共同特征是否属于同一技术语境和组合关系；
4. 以其为起点是否需要先改变基本原理、用途或工作条件；
5. 是否存在更自然的候选起点，且更换起点会不会实质改变后续三步法。

这些因素应综合权衡，不设置“一项为否即排除”的机械规则。

### 4. 选择分析处理方式

以下标签用于分析与方案判断。正式表达遵循 `legal-writing-style` 的正面论述要求，不据此自动生成批驳段落。

- **接受 D1**：起点合理，后续争点放在区别特征或技术启示。
- **接受起点但纠正公开认定**：D1 可用，但审查员夸大、错位或遗漏其公开内容。
- **保留异议并作双轨分析**：D1 起点有明显缺陷，同时以审查员 D1 和更合理候选分别验证结论。
- **直接挑战 D1**：只有起点缺陷明确且会实质影响创造性结论时使用。

即使挑战 D1，也应评估审查员以其他文件重新构造论证的可能性，避免作“D1 不合适所以必然授权”的结论。

|---|---|---|---|---|
| 技术领域/用途 | | | | |
| 技术问题 | | | | |
| 核心技术构思 | | | | |
| 共同特征 | | | | |
| 改进基础 | | | | |

结论使用以下之一，并说明理由：

- D1 是合理起点；
- D1 可作为起点，但公开认定需要纠正；
- D1 起点存在重大疑问，建议双轨分析；
- 另一候选更适合作为起点。

## 边界

D1 与 D2/Dn 是否能够组合、是否有反向教导、结合后能否成功，属于 `obviousness-assessment`。本 Skill 可记录会影响起点选择的明显事实，但不替代第三步判断。
