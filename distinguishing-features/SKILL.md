# 区别特征、技术效果与实际技术问题

处理顺序必须保持为：

```text
解释当前权利要求
→ 与 D1 整体对比
→ 确定区别特征及其组合关系
→ 确定这些差异达到的技术效果
→ 表述实际解决的技术问题
```

技术效果用于确定技术问题，不能反过来决定某个未写入权利要求的特征已经成为区别特征。

## 1. 解释并拆分当前权利要求

- 使用本次审查所依据的权利要求版本。
- 结合说明书解释术语，但不得把说明书限定自动读入权利要求。
- 拆分粒度以能够判断公开情况、组合关系和技术贡献为准；避免把一个相互作用的技术手段拆成失去意义的词语。
- 对功能上相互支持或存在相互作用的特征建立分组。

## 2. 与 D1 对比

对每个特征记录：

| 权利要求特征 | 权利要求位置 | D1 内容 | D1 位置 | 公开结论 | 说明 |
|---|---|---|---|---|---|

公开结论区分：

- 明确公开；
- 本领域技术人员从 D1 整体能够直接、明确得出的内容；
- 仅相似、仅上位概念或技术语境不同；
- 未公开；
- 材料不足，待核实。

不得把“具有类似功能”直接等同于公开了相同结构、步骤、参数或组合关系。附图推断须说明附图是否足以支持该结论。

## 3. 建立区别特征与效果的联系

技术效果可以来自：

- 说明书对发明目的、有益效果、实施例或对比例的记载；
- 本领域技术人员能够从原始申请文件公开内容中得知的效果；
- 由所述特征必然产生、且能够说明推理依据的效果。

技术效果不要求必须逐字写成“有益效果”，但不能在申请日后凭空创造。后补实验、补充解释或外部证据应单独标识，并核查其是否只是验证原始公开已经能够得知的效果。

输出关联表：

| 区别特征或特征组 | 技术效果 | 原始依据 | 因果关系强度 | 是否已进入权利要求 |
|---|---|---|---|---|

因果关系不明确时写“待验证”，不把并存关系写成因果关系。

对决定技术问题的效果，写清“区别特征在整体方案中改变了什么—该变化如何产生效果—相对于 D1 的改善或替代价值”。每个必要环节对应原始记载或可核验的技术推断。无需虚构微观机理；已有可靠实验支持时，说明比较条件和结果即可。D1 未报告某项性能时，不能直接认定其性能较差。

核查效果的适用范围：若结果依赖未进入权利要求的参数、材料或条件，说明其对当前主张的限制，转交修改模块评估；不得用单一实施例的优势概括整个保护范围。

## 4. 确定实际解决的技术问题

实际技术问题应反映区别特征相对于 D1 客观达到的技术效果：

- 不包含区别特征、解决手段或对答案的暗示；
- 不宽泛到“提高性能”“提供一种装置”；
- 不窄化为只有知道本申请方案才会提出的问题；
- 多个差异共同产生一个效果时，整体表述一个问题；
- 多个差异彼此独立、解决不同问题时，可以分别表述后再作整体评价；
- 如果差异带来的效果与 D1 相同或相当，可以将问题表述为提供具有相同或相当效果的替代方案。

说明书记载的发明目的应结合 D1 重新核查；若 D1 已经解决该问题，应根据客观差异及其效果重新确定。

### 表述与核验

先说明 D1 在相关条件下已达到的效果，再说明区别特征所带来的、证据能够支持的变化，最后用一句简明表述确定技术问题。必要的应用条件用于界定问题；只在本申请方案中出现的结构、步骤、参数及组合关系留在解决手段的分析中。

逐项检查：

- 问题中的对象、条件和改善目标是否都有依据；“提高性能”应具体到已证实的性能维度，避免堆叠安全性、稳定性、效率等无关联目标。
- 暂时隐去本申请解决手段后，该问题能否仅根据 D1 与已确认的差异效果成立。若必须知道答案才能提出该问题，重新调整抽象层次。
- 是否把“不采用某结构”“无需某步骤”等区别特征改写成约束，从而暗含答案；只有存在独立技术依据的约束才保留。
- 删除某个条件是否会使问题失去技术意义；保留某个条件是否会预先限定本申请路径。按这两端校准具体程度。
- 效果不明确时记录候选问题及各自证据缺口，暂不确定；“提供替代方案”也须有相同或相当效果的依据。

分析稿同时给出问题表述及其推导依据。正式成稿只保留有证据支撑的表述和必要说明，不堆列多个版本。

## 5. 输出

以下为分析记录，可按争点用表格或文字呈现，无需在正式文书中逐项照抄。传给第三步的技术问题须连同其效果、出处、因果依据及适用条件，不只传递一句问题表述。

### 三步法第二步结论

1. 当前权利要求及解释前提；
2. 逐特征对比表；
3. 区别特征及合理分组；
4. 每组差异的技术效果、出处和证据强度；
5. 实际解决的技术问题；
6. 审查员认定与独立结论的差异；
7. 仅存在于说明书、可供修改评估的候选限定。

## 自检

- 区别特征是否都来自当前权利要求；
- 是否保留了特征间关系而非机械拆散；
- 技术效果是否能从原始公开中得知；
- 技术问题是否暗含解决手段；
- 是否考虑“替代方案”情形；
- 是否把事实判断、技术推断和待核实内容分开。
